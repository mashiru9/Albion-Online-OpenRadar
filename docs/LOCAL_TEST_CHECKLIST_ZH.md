# Windows 本地测试清单

本清单用于 `D:\Projects\Albion-Online-OpenRadar` 的本地只读雷达验证。运行时不需要管理员权限；Npcap 已安装后，不应再修改防火墙、代理、VPN、hosts、网卡或安全软件设置。

## 1. 启动前

- [ ] 普通用户 PowerShell 中执行 `powershell -ExecutionPolicy Bypass -File .\scripts\check-environment.ps1`，结果为通过。
- [ ] Node.js、npm、Go、Git 和 Npcap 服务可用。
- [ ] TCP 端口 5001 空闲；若被占用，先确认占用者，不要由脚本强制终止进程。
- [ ] `node_modules` 已由 `npm ci` 安装。
- [ ] 不以管理员身份启动雷达，不启动游戏，不改系统网络或安全配置。

## 2. 启动与基本连通性

- [ ] 执行 `powershell -ExecutionPolicy Bypass -File .\scripts\start-windows-dev.ps1`。
- [ ] 终端完成 CSS、vendors 构建，并启动 Go 后端。
- [ ] 浏览器打开 `http://127.0.0.1:5001`，页面标题和布局正常。
- [ ] 页面显示后端已连接，WebSocket 保持连接。
- [ ] CSS、JavaScript、字体、图标均加载，无浏览器控制台错误。
- [ ] items、mobs、harvestables、zones 数据库请求均返回成功。

## 3. 网卡与抓包

- [ ] 网卡列表能区分物理以太网、Wi-Fi、VPN/加速器和虚拟网卡。
- [ ] 自动选择符合条件的活动网卡；必要时仅在应用内手动选择正确网卡。
- [ ] 抓包状态为 running，且至少有一个活动 capture。
- [ ] 不开启原始 802.11、仅管理员抓包或 WinPcap 兼容模式。
- [ ] `network.json` 仅保存在本机且被 Git 忽略。

## 4. 地图与本地玩家

- [ ] 进入区域后，区域名称、地图边界和缩放正常更新。
- [ ] 本地玩家标识和本地可用坐标按当前协议能力显示。
- [ ] 切区、死亡、回城或断线重连后，旧区域对象被清理。
- [ ] 地图缩放、拖动、筛选和显示开关不会导致页面卡死。

## 5. 资源

- [ ] 木材、矿石、纤维、皮革、石头等资源类型可正确区分。
- [ ] T2-T8 等级、附魔层级和图标/颜色与实际对象一致。
- [ ] 活体、可采集、枯竭或剩余量状态按协议数据更新。
- [ ] 资源出现、更新、消失以及切区后的清理均正常。
- [ ] 资源筛选、距离或显示限制不会留下陈旧对象。

## 6. 生物、地下城和世界对象

- [ ] 普通怪、精英、Boss 与特殊目标的名称/类型显示合理。
- [ ] Mists、Roads of Avalon 等区域中的对象不会错误继承旧地图数据。
- [ ] 单人/团队地下城、入口、传送门、宝箱等对象能按支持范围显示。
- [ ] 对象生成、状态更新、死亡/消失和超时清理正常。

## 7. 其他玩家与提醒

- [ ] 仅验证协议当前可提供的玩家元数据、列表和提醒。
- [ ] 敌对玩家的实时坐标当前不可用，不应将列表存在误认为地图定位。
- [ ] 姓名、联盟/公会、装备或其他可用字段更新合理。
- [ ] 玩家进入、离开、断线或切区后，陈旧条目被清理。
- [ ] 声音/视觉提醒不重复轰炸，过滤条件有效。

## 8. 日志与错误检查

- [ ] 检查 `logs/sessions`、`logs/debug`、`logs/errors` 和 `logs/captures`。
- [ ] 正常运行无 panic、持续重连、数据库 404 或抓包初始化失败。
- [ ] 日志、网络配置和抓包文件均保持未跟踪/忽略，不提交隐私数据。
- [ ] 报告问题前移除 IP、MAC、角色名、会话内容和其他敏感信息。

## 9. 停止与复测

- [ ] 在启动雷达的 PowerShell 中按一次 `Ctrl+C`，等待后端退出。
- [ ] 确认端口 5001 已释放，没有残留 `radar` 进程。
- [ ] 执行 `powershell -ExecutionPolicy Bypass -File .\scripts\test-windows.ps1`。
- [ ] `go test ./...`、`npm test`、`npm run typecheck`、`npm run lint` 全部通过。
- [ ] 再次启动后可重复连接和抓包，且无需重新安装 Npcap。

## 安全边界

该项目的验证范围仅限本机网络包的被动解析和页面展示。不进行协议解密、进程注入、内存读取、反作弊规避或自动化游戏操作。测试中发现能力边界时，应如实记录，不通过扩大系统权限或修改安全设置绕过。
